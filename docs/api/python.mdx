```bash
pip install qrcode-ai-scanner
```

One `abi3` wheel covers CPython 3.8 → 3.14. Prebuilt for macOS (arm64/x64),
Linux (manylinux + musllinux, x64/aarch64), and Windows (x64). The scan releases
the GIL, so it never blocks other Python threads.

## API

```python
import qrcode_ai_scanner as q

# encoded image (PNG · JPEG · WebP · GIF) → ScanReport as a dict
report = q.scan(
    image_bytes,
    "full",              # "full" | "fast" | "frame"   (default "full")
    max_dimension=4096,  # anti-DoS — LOWER THESE for untrusted uploads
    max_pixels=16_000_000,
    alpha_background="auto",  # background under transparent pixels:
                              # "auto" | "white" | "black" | "none" | "#rrggbb"
                              # (opaque inputs untouched; result in report["alpha"])
)

# raw RGBA camera frame (width * height * 4 bytes), no format roundtrip
frame = q.scan_frame(rgba_bytes, width, height, "frame")

q.version()  # "0.4.0"
```

`scan` / `scan_frame` return the [`ScanReport`](/api/report) as a plain dict
(`detections`, `score`, `hints`, `trace`, `versions`) — schema-conformant, since
the dict is built from the same serde JSON every binding ships. Types ship too
(`qrcode_ai_scanner.pyi`).

Each detection's `content` carries the payload's bytes (`raw`, base64: the
original bytes for the QR family, the decoding engine's reading for other
symbologies), their reading (`text`) and how the two relate (`charset`:
`utf8` · `shift_jis` ·
`latin1` · `gb18030` · `eci` · `unknown`). Test `charset == "unknown"` — the
only lossy value: there is no verified reading, use `raw`. The optional `eci`
and `fnc1` keys carry the ECI designators and the FNC1 position; compare
contents by `symbology`, `raw`, `fnc1` and `eci`, never by `text`.

## Recipe (upload endpoint)

```python
def handle_upload(image_bytes: bytes) -> dict:
    try:
        report = q.scan(image_bytes, "full", max_dimension=4096, max_pixels=16_000_000)
    except ValueError as e:
        # message carries the wire code, e.g. "...: bad image [QRS-001]"
        raise BadRequest(str(e))
    if not report["detections"]:
        return {"ok": False, "reason": "no_qr"}      # not an error — just empty
    d = report["detections"][0]
    untrusted = any(h["hint"] == "low_correction_margin" for h in report["hints"])
    # None = not judged (the budget cut it, or no score in this profile), never 0
    return {"ok": True, "text": d["content"]["text"], "kind": d["payload"]["kind"],
            "score": (report["score"] or {}).get("value"),
            "final": report["trace"]["budget_exhausted"] is False, "untrusted": untrusted}
```

`budget_ms` overrides the profile's wall-clock budget: unset keeps the
profile default (full 4000 · fast 800 · frame 80 ms), `0` is unbounded and
the only strictly reproducible mode. A report the budget cut says so —
`report["trace"]["budget_exhausted"]` is `True` — and is partial: empty
detections are not final, and a `None` score beside a detection means "not
judged".

Invalid input / a bad profile raises `ValueError` with a `[QRS-xxx]`-tagged
message ([catalog](/api/errors)). The report shape is the [one contract](/api/report).
