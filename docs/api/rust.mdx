```bash
cargo add qrcode-ai-scanner
```

Features: `engine-rxing` + `engine-rqrr` (default — at least one
required) · `parallel` (rayon batching, native only — OFF for wasm) ·
`serde` (the JSON contract).

## Scanner

`Send + Sync`, no interior state — build once, share across threads.

```rust
use qrcode_ai_scanner::{
    CancelToken, ImageInput, Limits, ScanConfig, ScanProfile, Scanner,
};

let scanner = Scanner::builder()
    .profile(ScanProfile::Full)          // Full | Fast | Frame | Custom(_)
    .limits(Limits { max_dimension: 4096, max_pixels: 16_000_000, ..Limits::default() })
    .build();
```

### Inputs

| Constructor | Use |
|---|---|
| `ImageInput::encoded(&bytes)` | PNG / JPEG / WebP / GIF bytes |
| `ImageInput::rgba8(&buf, w, h)` | camera frames (`ImageData`-shaped, no PNG roundtrip) |
| `ImageInput::luma8(&buf, w, h)` | pre-converted grayscale |

### Scanning

```rust
// the standard call — "no QR" is Ok(empty), never Err
let report = scanner.scan(ImageInput::encoded(&bytes))?;

// cooperative cancellation (checked between attempts/cells)
let cancel = CancelToken::new();
let handle = cancel.clone();           // fire from another thread
let report = scanner.scan_cancellable(ImageInput::encoded(&bytes), &cancel)?;

// batch — parallel under the `parallel` feature, per-input Results
let reports = scanner.scan_batch(&inputs);
```

### Custom profiles

```rust
let mut config: ScanConfig = ScanProfile::Full.config(); // preset → adjust
// None = unbounded, the reproducible mode; with a budget, a cut report
// says so (`report.trace.budget_exhausted == Some(true)`) and a judgment
// it interrupts is `score: None`, never partial
config.budget_ms = Some(1_500);
// background under transparent pixels — AlphaBackground::from_name parses
// "auto" | "white" | "black" | "none" | "#rrggbb" (opaque inputs untouched)
config.alpha_background = AlphaBackground::Custom([0x1a, 0x1a, 0x2e]);
let scanner = Scanner::builder()
    .profile(ScanProfile::Custom(config))
    .build();
```

`config.computes_score()` says whether a configuration plans a judgment at
all (`false` for the `Frame` profile or every stress axis skipped).

### Reading content

```rust
for d in &report.detections {
    let bytes: &[u8] = &d.content.raw;   // the payload's bytes (QR family: the original)
    if d.content.charset.is_lossy() {
        // `Charset::Unknown`, the only lossy value: no verified reading — use `raw`
    } else {
        println!("{}", d.content.text);  // `raw` read as `charset` says
    }
    // d.content.eci:  Option<Vec<EciSegment>> — located designators;
    //                 Some(vec![]) = an ECI signalled but not located
    // d.content.fnc1: Option<Fnc1Position>    — First (GS1) | Second
}
```

Two detections denote the same content when symbology, `raw`, `fnc1` and
`eci` agree (spec/01 § Comparing contents) — never key on `text`.

### Errors

`ScanError` (`thiserror` + `miette`): `.code()` → `"QRS-001"…"QRS-005"`
([catalog](/api/errors)). Pattern-match the code, not the variant — the
enum is `#[non_exhaustive]`.

## Type surface

Everything the report contains is re-exported at the crate root:
`ScanReport` · `Detection` · `DecodedContent` · `Payload` · `Gs1Element` ·
`Score` · `UecReport`/`UecGrade` · `Iso15415Report`/`IsoGrade`/`IsoParameter` ·
`Hint` · `StructuralReport` · `PipelineTrace` · `EngineKind` · `QrMeta` ·
`Grade` · `StressAxis` · `Charset` · `EciSegment` · `Fnc1Position` ·
`EcLevel` · `Point` · `Versions`.
All public enums/structs are `#[non_exhaustive]` — match with `_` arms.
